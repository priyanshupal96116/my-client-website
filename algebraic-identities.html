Exploring Algebraic Identities

Aaj hum algebraic identities ko samjhenge, diagrams se dekhenge aur khud questions solve karenge.

1. Algebraic identity kya hoti hai?

Algebraic identity ek aisa mathematical rule hai jo variables ki sabhi allowed values ke liye true hota hai.

Example: (a + b)² = a² + 2ab + b²

Identity ko area se samjho

Total area = a² + ab + ab + b² = a² + 2ab + b²

Yaad rakho: square ka area = side × side.

2. Identity: (a + b)²

(a + b)² = a² + 2ab + b²

Jab do terms add karke unka square karna ho, tab yeh identity useful hoti hai.

Teen area parts

Solved example

Expand (x + 3)².

  1. Identity: (a + b)² = a² + 2ab + b²
  2. Yahan a = x aur b = 3.
  3. = x² + 2 × x × 3 + 3²
  4. = x² + 6x + 9

Daily-life trick: 21² = (20 + 1)² = 400 + 40 + 1 = 441.

3. Identity: (a − b)²

(a − b)² = a² − 2ab + b²

Jab ek term mein se doosri term subtract ho aur poore bracket ka square ho, tab yeh identity use karo.

Expansion ke signs samjho

Solved example

Expand (x − 4)².

  1. = x² − 2 × x × 4 + 4²
  2. = x² − 8x + 16

Answer: x² − 8x + 16

Common mistake: last term positive hota hai, kyunki (−4)² = +16.

4. Identity: (a + b)(a − b)

(a + b)(a − b) = a² − b²

Isse difference of two squares bhi kehte hain. Dono brackets mein pehla term same aur doosra term opposite sign mein hota hai.

Middle terms cancel ho jaate hain

Solved example

Simplify (x + 5)(x − 5).

  1. Identity use karo: (a + b)(a − b) = a² − b²
  2. = x² − 5²
  3. = x² − 25

Daily-life trick: 49 × 51 = (50 − 1)(50 + 1) = 2500 − 1 = 2499.

5. Identity: (x + a)(x + b)

(x + a)(x + b) = x² + (a + b)x + ab

Jab dono brackets mein x ho aur doosre numbers alag hon, tab yeh identity helpful hai.

Example: (x + 2)(x + 3)

Solved example

(x + 2)(x + 3)

  1. = x² + (2 + 3)x + 2 × 3
  2. = x² + 5x + 6

6. Useful square identity: (a + b + c)²

(a + b + c)² = a² + b² + c² + 2ab + 2bc + 2ca

Teen terms ka sum square karte waqt, har term ka square aur har pair ka double product add hota hai.

Teen terms, teen pair products

Solved example

Expand (x + y + 1)².

= x² + y² + 1 + 2xy + 2y + 2x

Answer: x² + y² + 1 + 2xy + 2y + 2x

7. Algebraic identities se factorisation

Identity ko ulta use karke expression ko factors mein likh sakte hain.

a² − b² = (a + b)(a − b)
a² + 2ab + b² = (a + b)²
a² − 2ab + b² = (a − b)²

Solved example

Factorise x² − 36.

  1. 36 = 6², isliye x² − 36 = x² − 6²
  2. Difference of squares use karo.
  3. Answer: (x + 6)(x − 6)

8. Common mistakes

  • (a + b)² ko a² + b² likhna galat hai; 2ab bhi aata hai.
  • (a − b)² ka middle term −2ab hota hai.
  • (a + b)(a − b) mein result a² − b² hota hai.
  • Bracket ke bahar square ho to har term ko sahi tarah expand karo.

Show Full Solution

Concept / method: Use (x+y+z)²=x²+y²+z²+2xy+2yz+2zx, with z=2.

Final answer: a² + b² + 4 + 2ab + 4b + 4a

Challenge • Question 10

Evaluate 103² using an identity.

Show Full Solution

Concept / method: 103=100+3. Then (100+3)²=10000+600+9.

Final answer: 10609
