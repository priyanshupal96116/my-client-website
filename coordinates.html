CLASS 9 MATHS · COORDINATE GEOMETRY

Orienting Yourself: The Use of Coordinates

Aaj hum seekhenge graph par kisi point ki exact location kaise batate hain. X-axis, Y-axis, origin, quadrants aur ordered pairs ko easy Hinglish mein samjhenge.

1. Coordinate Geometry kya hai?

Coordinate Geometry maths ki woh branch hai jisme hum numbers ki madad se kisi point ki location graph par batate hain.

Daily-life example: Socho school ka map ek grid hai. Agar library point (2, 3) par hai, to origin se 2 units right aur 3 units up jaakar library ki location mil sakti hai.

2. Cartesian plane aur axes

Cartesian plane mein do number lines ek doosre ko 90° par cut karti hain.

  • X-axis: Horizontal line, left-right direction.
  • Y-axis: Vertical line, up-down direction.
  • Origin: Dono axes ka intersection point, (0, 0).

X-axis par har point ka y-coordinate 0 hota hai, jaise (3, 0). Y-axis par har point ka x-coordinate 0 hota hai, jaise (0, 4).

3. Ordered pair (x, y)

Kisi point ko hum ordered pair (x, y) se likhte hain. Pehla number x-coordinate aur doosra number y-coordinate hota hai.

(x, y) = (horizontal position, vertical position)

Example: Point P(−2, 3).

  • x-coordinate = −2, yaani origin se 2 units left.
  • y-coordinate = 3, yaani origin se 3 units up.
Yaad rakho: Pehle x direction mein move karo, phir y direction mein. Order badalne se point badal sakta hai: (2, 3) aur (3, 2) alag points hain.

4. Graph par point plot karna

Point A(3, 2) plot karne ke steps:

  1. Origin (0, 0) se start karo.
  2. X-axis par 3 units right jao.
  3. Wahan se 2 units up jao.
  4. Point mark karke A likho.

5. Four quadrants

X-axis aur Y-axis plane ko chaar regions mein divide karte hain. In regions ko quadrants kehte hain.

  • Quadrant I: x positive, y positive.
  • Quadrant II: x negative, y positive.
  • Quadrant III: x negative, y negative.
  • Quadrant IV: x positive, y negative.

Axes par maujood points kisi quadrant ke andar nahi hote.

6. Solved examples

Example A:

Point B(4, 0) kis axis par hai?

Y-coordinate 0 hai, isliye point X-axis par hai.

Example B:

Point C(0, −5) kis axis par hai?

X-coordinate 0 hai, isliye point Y-axis par hai.

Example C:

Point D(−3, 2) kis quadrant mein hai?

x negative aur y positive hai, isliye Quadrant II.

7. Extra concept: Distance between two points

Do points ke beech seedhi line ki distance find karne ke liye distance formula use hota hai. Yeh ek additional concept hai; pehle coordinates aur graph plotting par pakad banao.

AB = √[(x₂ − x₁)² + (y₂ − y₁)²]
Example: A(1, 2), B(4, 6).

AB = √[(4 − 1)² + (6 − 2)²]

= √[9 + 16] = √25 = 5 units.

8. Common mistakes

  • (x, y) mein x aur y ki positions ulat dena.
  • Negative coordinate ka sign bhool jaana.
  • Point plot karte waqt pehle x aur phir y move na karna.
  • Axes par points ko kisi quadrant mein count karna.

10. Quick revision

  • Ordered pair (x, y) point ki position batata hai.
  • X-axis horizontal aur Y-axis vertical hoti hai.
  • Origin = (0, 0).
  • Axes plane ko four quadrants mein divide karti hain.
  • Point plot karte waqt pehle x, phir y direction follow karo.
Study tip: Notebook mein axes banao aur (2,3), (−2,3), (−2,−3), (2,−3) points khud plot karke dekho.

Easy • Question 1

Concept / method: The origin is where the x-axis and y-axis meet. Both coordinates are zero.

Concept / method: In (x, y), the first number is x and the second number is y.

Final answer: x = 4, y = −3

Easy • Question 3

Which quadrant contains (−2, 5)?

Concept / method: x is negative and y is positive. The sign pattern (−, +) is Quadrant II.

Final answer: Quadrant II

Easy • Question 4

Which quadrant contains (3, −4)?

Show Full Solution

Concept / method: x is positive and y is negative. The sign pattern (+, −) is Quadrant IV.

Final answer: Quadrant IV

Medium • Question 5

State the signs of x and y in Quadrant III.

Show Full Solution

Concept / method: Quadrant III is left of the y-axis and below the x-axis.

Final answer: x < 0 and y < 0

Medium • Question 6

A point is 5 units right and 2 units above the origin. Write its coordinates.

Show Full Solution

Concept / method: Right means positive x; above means positive y.

Final answer: (5, 2)

Medium • Question 7

A point is 4 units left and 3 units below the origin. Write its coordinates.

Show Full Solution

Concept / method: Left gives x = −4; below gives y = −3.

Final answer: (−4, −3)

Medium • Question 8

Does (0, 6) lie in a quadrant? Explain.

Show Full Solution

Concept / method: A point with x = 0 lies on the y-axis, not inside a quadrant.

Final answer: No; it lies on the positive y-axis.

Challenge • Question 9

Find the distance between A(1, 2) and B(4, 6).

Show Full Solution

Concept / method: Distance = √[(x₂−x₁)²+(y₂−y₁)²] = √[(4−1)²+(6−2)²] = √(9+16) = √25.

Final answer: 5 units

Challenge • Question 10

P has x-coordinate −3 and lies on the x-axis. Write P.

Show Full Solution

Concept / method: Every point on the x-axis has y = 0.

Final answer: P = (−3, 0)
