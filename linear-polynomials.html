Introduction to Linear Polynomials

Aaj hum seekhenge polynomial kya hota hai, uski degree kaise nikalte hain aur linear polynomial ko kaise solve karte hain.

1. Polynomial kya hota hai?

Polynomial ek mathematical expression hai jisme numbers aur variables (jaise x, y) hote hain. Variables ki powers non-negative whole numbers hoti hain.

3x + 5

Is expression mein:

  • x = variable
  • 3 = x ka coefficient
  • 5 = constant term
  • + = addition ka sign
Yaad rakho: x² + 2x + 1 ek polynomial hai, lekin 1/x + 2 polynomial nahi hai, kyunki x denominator mein aane par power −1 ho jaati hai.

2. Polynomial ki degree

Ek variable wale non-zero polynomial mein variable ki sabse badi power uski degree hoti hai.

4x³ + 2x² − 7x + 6

Ismein x ki powers 3, 2 aur 1 hain. Sabse badi power 3 hai, isliye is polynomial ki degree 3 hai.

Polynomial Degree Type
7 0 Constant polynomial
3x + 2 1 Linear
x² + 4x + 1 2 Quadratic
x³ − 2x + 5 3 Cubic
Important: Zero polynomial (0) ki degree ko aam taur par undefined maana jaata hai.

3. Linear polynomial kya hai?

Jis non-zero polynomial ki degree 1 hoti hai, use linear polynomial kehte hain.

p(x) = ax + b, where a ≠ 0

Examples:

  • 2x + 3
  • 5x − 7
  • −x + 4

Yahan a aur b constants hain. a, x ka coefficient hai aur b constant term hai.

Diagram ek straight line ka idea dikhata hai. Linear polynomial aur usse related equation ka graph samajhne mein yeh useful hai.

4. Daily-life example

Maan lo ek notebook ₹20 ki hai aur delivery charge ₹10 hai. Agar tum x notebooks khareedte ho, to total cost hogi:

C = 20x + 10

Agar 3 notebooks khareedo:

Step 1: x = 3 rakho.

Step 2: C = 20 × 3 + 10

Step 3: C = 60 + 10 = ₹70

Answer: ₹70

5. Polynomial ki value kaise nikaalein?

Polynomial ki value nikalne ke liye variable ki jagah di hui value rakhte hain. Is process ko substitution kehte hain.

Question: p(x) = 3x − 2 ke liye p(4) nikaalo.

Step 1: x = 4 rakho.

p(4) = 3(4) − 2

Step 2: Multiply karo.

p(4) = 12 − 2

Step 3: Subtract karo.

p(4) = 10

Answer: 10

6. Zero of a polynomial

Polynomial ki woh value jise rakhne par answer 0 aaye, polynomial ka zero kehlati hai.

Example: p(x) = 2x − 6

Zero nikalne ke liye p(x) = 0 rakho.

2x − 6 = 0
2x = 6
x = 3

Check: p(3) = 2(3) − 6 = 0. Isliye 3 is polynomial ka zero hai.

Dhyaan do: Polynomial ka zero aur polynomial ki degree alag cheezein hain. Degree powers batati hai, jabki zero woh value hoti hai jahan polynomial ki value 0 ho.

8. Quick revision

  • Variable: x ya y jaise letter.
  • Coefficient: variable ke saath multiply hone wala number.
  • Degree: non-zero polynomial ki highest power.
  • Linear polynomial: degree 1, jaise 2x + 3.
  • Polynomial ka zero: woh value jahan polynomial 0 ho.
