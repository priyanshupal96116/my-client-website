CLASS 9 MATHS · NUMBER SYSTEM

The World of Numbers

Numbers ko ratna nahi, samajhna hai! Is chapter mein number line, rational aur irrational numbers, square roots aur decimal expansions ko examples aur diagrams se seekhenge.

1. Numbers ki duniya

Socho tumhare paas ₹20 hain. Tum ₹7 kharch karte ho, toh ₹13 bachte hain. Yahan counting, subtraction aur numbers ka use hota hai.

Maths mein alag situations ke liye alag types ke numbers use hote hain.

1.1 Natural numbers

Counting ke numbers: 1, 2, 3, 4, 5, ...

Example: 5 students, 12 pencils, 3 books.

1.2 Whole numbers

Natural numbers ke saath zero bhi: 0, 1, 2, 3, 4, ...

Example: Box mein koi pencil nahi hai, toh pencils ki sankhya 0 hai.

1.3 Integers

Positive numbers, zero aur negative numbers milkar integers bante hain.

Examples: −3, −2, −1, 0, 1, 2, 3

Daily life: Temperature 4°C se girkar −2°C ho sakta hai.

2. Number line ko samjho

Number line ek seedhi line hoti hai jis par numbers ko unki position ke hisaab se dikhate hain.

  • Right side jaane par numbers bade hote hain.
  • Left side jaane par numbers chhote hote hain.
  • Zero na positive hai na negative.

Solved example

Temperature −2°C hai. Temperature 5°C badh gaya. Naya temperature?

  1. Starting temperature = −2°C
  2. Increase = +5°C
  3. Calculate: −2 + 5 = 3

Answer: 3°C

3. Rational numbers

Aisa number jise p/q ke form mein likh sakein, jahan p aur q integers hon aur q ≠ 0, rational number kehlata hai.

Rational number = p/q, where q ≠ 0

Examples: 1/2, −3/4, 5, 0.25.

Whole number 5 bhi rational hai, kyunki 5 = 5/1.

Decimal expansion

  • Terminating decimal: decimal digits khatam ho jaate hain. Example: 1/4 = 0.25.
  • Non-terminating recurring: digits chalte rehte hain lekin pattern repeat hota hai. Example: 1/3 = 0.333...
Example: 3/8 ko decimal mein badlo.
  1. 3 ÷ 8 karo.
  2. Result 0.375 aata hai.
  3. Decimal khatam ho gaya, isliye yeh terminating decimal hai.

4. Irrational numbers

Aise real numbers jinhe do integers ke ratio p/q ke roop mein exactly nahi likh sakte, irrational numbers kehlate hain.

Examples: √2, √3, π.

Inki decimal expansion non-terminating aur non-recurring hoti hai — yani decimal na khatam hota hai aur na hi digits ka koi fixed pattern baar-baar repeat hota hai.

Important: Har non-terminating decimal irrational nahi hota. 0.333... repeat hota hai, isliye rational hai.

5. Square roots aur perfect squares

Square root ka matlab: kaunsa number khud se multiply karne par diya hua number deta hai?

√a = b means b × b = a (for non-negative a and b)
NumberSquareSquare root
11 × 1 = 1√1 = 1
42 × 2 = 4√4 = 2
93 × 3 = 9√9 = 3
255 × 5 = 25√25 = 5
497 × 7 = 49√49 = 7
819 × 9 = 81√81 = 9

Solved example: √144

  1. Socho kaunsa number khud se multiply hokar 144 deta hai.
  2. 12 × 12 = 144.
  3. Isliye √144 = 12.

√2 irrational kyun hai?

√2 ki value lagbhag 1.414213... hai. Iska decimal na khatam hota hai aur na hi koi fixed repeating pattern follow karta hai. Isliye √2 irrational hai.

6. Real numbers aur unki position

Rational aur irrational numbers dono real numbers hain. Number line par har real number ki ek position hoti hai.

Diagram approximate hai. √2, 1 aur 2 ke beech aata hai; √3 bhi 1 aur 2 ke beech hai, lekin √2 se bada hai.

7. Common mistakes

  • √49 = ±7 nahi, principal square root √49 = 7 hota hai. Equation x² = 49 ke solutions +7 aur −7 hain.
  • 0 rational number hai, kyunki 0 = 0/1.
  • Har decimal irrational nahi hota. Terminating aur recurring decimals rational hote hain.
  • Fraction p/q mein denominator q zero nahi ho sakta.

8. Practice questions

Pehle khud solve karo, phir answer reveal karna.

Q1. Inmein se irrational number kaunsa hai?
Correct: √3. Iska decimal non-terminating aur non-recurring hai.
Q2. √81 ki value kya hai?
Correct: 9, kyunki 9 × 9 = 81.
Q3. Kaunsa number rational hai?
Correct: 0.333... kyunki yeh repeating decimal hai aur 1/3 ke barabar hai.
Q4. −4 aur 2 mein number line par kaunsa left side par hoga?
Correct: −4. Number line par chhota number left side hota hai.

9. Chapter revision

  • Natural: 1, 2, 3, ...
  • Whole: 0, 1, 2, 3, ...
  • Integers: ..., −2, −1, 0, 1, 2, ...
  • Rational: p/q, where q ≠ 0.
  • Irrational: decimal non-terminating and non-recurring.
  • Real numbers: rational and irrational numbers together.
  • Perfect square: integer ka square, jaise 1, 4, 9, 16, 25, ...
Study tip: Har example ko copy mein khud solve karo. Agar answer galat ho, toh steps ko dobara check karo.
